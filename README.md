## About this project

I made this portfolio as part of my work at **EPITECH Paris**. I wanted a website that was simple to navigate but still felt personal. I chose a dark green and cream color palette and built everything using HTML and CSS.

It includes my studies, my programming projects, my skills, and a few interests that are important to me.

## What's inside?

| Page | What you'll find |
| --- | --- |
| `index.html` | Introduction and featured projects |
| `about.html` | My background, education, and journey |
| `projects.html` | Projects, technologies, and GitHub links |
| `skills.html` | Technical skills and what I've learned |
| `beyond.html` | Painting, photography, music, and debating |
| `contact.html` | Ways to contact me |

All the pages use the same `style.css` file.

## Built with

- **HTML5** for the pages and their content
- **CSS3** for the colors, layout, and responsive design
- **Git & GitHub** to keep track of changes

## Run it locally

1. Download this repository or clone it.
2. Open the portfolio folder in VS Code.
3. Open `index.html` in your browser (or use the Live Server extension).
